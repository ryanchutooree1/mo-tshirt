## Mac remote-use setup
Keep-awake service label: com.motshirt.remote-keep-awake
Uses the macOS caffeinate tool to prevent idle display and system sleep.
Screen saver idleTime changed from 300 seconds to 0 for remote use.
Password and authentication settings were not changed.
Keep the Mac plugged in, with its lid open. This cannot prevent a power loss, manual lock, shutdown or restart.

To restore normal behavior later:
```sh
launchctl remove com.motshirt.remote-keep-awake
defaults -currentHost write com.apple.screensaver idleTime -int 300
```
